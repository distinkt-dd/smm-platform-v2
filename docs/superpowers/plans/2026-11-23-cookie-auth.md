# Cookie-сессия и защищённый маршрут

**Результат:** токен недоступен JavaScript, вход восстанавливается после перезагрузки, выход очищает cookie, главная страница доступна только после проверки сессии.

**Подход:** backend выдаёт HttpOnly-cookie с access JWT и проверяет Origin и специальный заголовок на изменяющих браузерных запросах; frontend отправляет cookie автоматически и восстанавливает пользователя через `/auth/me`.
