# Концепция продукта

Название приложения — **SMM в кармане**.

Цель — помочь самостоятельному бьюти-мастеру создавать контент через описание задачи в чате, затем постепенно автоматизировать SMM, включая публикацию. Продукт рассчитан на разные бьюти-направления с первого этапа. Часть учебных примеров относится к перманентному макияжу.

Основное устройство — телефон. На первом этапе пользователь создаёт контент для своей страницы.

## Форматы

- Отдельное оформленное изображение на основе фотографии пользователя.
- Отдельный видеоролик, в том числе монтаж из фотографий и клипов.
- Серия сторис: последовательность самостоятельных изображений и видео.

В интерфейсе различать формат результата и исходные материалы. Фотография может быть самостоятельным результатом либо материалом сцены ролика. Не называть любое изображение рилсом.

## Основной сценарий

1. Пользователь описывает цель и прикладывает материалы; может выбрать сохранённую тему или дать референсы.
2. Чат использует профиль, методологию и материалы; уточняет критичные недостающие факты.
3. Система предлагает план: для фото — текст и оформление, для видео — сцены и материалы, для серии — порядок элементов.
4. Пользователь корректирует и согласовывает план.
5. Система создаёт результат и показывает превью.
6. Пользователь просит изменения через чат, затем одобряет готовый результат либо отклоняет его.
7. Одобренный контент сохраняется; оформление попадает в личную библиотеку тем или обновляет выбранную тему.
8. Пользователь выбирает подключённую страницу и нажимает «Опубликовать»; система подготавливает и отправляет контент, затем показывает статус.

Одобрение готового контента и команда отправки — разные действия. В текущем дизайне используется явная кнопка «Опубликовать». Пользователю не требуется вручную переносить готовую серию в соцсеть.

## Подключение соцсетей и автоматизация публикации

Пользователь привязывает свои соцсети в профиле; платформа берёт на себя подготовку контента и публикацию после проверки и команды пользователя. Основной принцип — минимум ручных действий: поставить задачу, приложить материал, согласовать план, проверить и поправить результат, отправить.

AI помогает с содержанием и оформлением; отправку должна выполнять серверная интеграция выбранной площадки. Выбор площадок, возможности их API и разрешения ещё предстоит проработать.

Показывать аккаунт назначения и состояния отправки. Повторное подключение и ошибки должны давать понятный путь продолжения. Возможность публикации автоматически сразу после одобрения, без отдельного нажатия «Опубликовать», остаётся открытой; не включать её по умолчанию.

## Персонализация и темы

Чат автоматически учитывает обратную связь конкретного пользователя. Пользователь выбирает тему из личной подборки с превью или скриншотами ранее настроенных работ. Помимо изображений тема хранит параметры, необходимые для воспроизведения оформления: например, цвета, шрифты, размещение текста, переходы и темп.

До одобрения изменения действуют в текущей задаче. После одобрения тема автоматически сохраняется или обновляется; предыдущую версию можно вернуть. При одобрении без выбранной темы создаётся новая. Если тема была выбрана, создаётся её новая версия.

Сведения о мастере, его услугах и подтверждённые факты отделяются от визуального оформления. Персонализация через профиль, правила и примеры — принятый начальный подход; дообучение модели не согласовано.
