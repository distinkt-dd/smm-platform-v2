# SMM Platform 2

«SMM в кармане» помогает самостоятельным бьюти-мастерам создавать контент для своих страниц и публиковать его после проверки.

- [Карта проекта](docs/code-map/README.md) помогает выбрать документы и точки входа по задаче.
- [Правила работы](AGENTS.md) описывают роли, порядок ревью и работу с Git.

Базовые приложения и команды запуска описаны в [карте структуры](docs/code-map/foundation.md). Прикладные модули будут добавляться по мере разработки.
