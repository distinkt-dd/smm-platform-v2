# SMM Platform 2

«SMM в кармане» помогает самостоятельным бьюти-мастерам создавать контент для своих страниц и публиковать его после проверки.

- [Graphify](docs/graphify.md) помогает исследовать структуру и связи backend и frontend.
- [Правила работы](AGENTS.md) описывают роли, порядок ревью и работу с Git.

Контракты модулей, точки входа и команды проверок описаны в [структуре приложений](docs/foundation.md).
